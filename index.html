iOS: install and update

Add to AltStore Add to SideStore

Source URL: https://g.aribas.dev/altstore.json

  1. AltStore or SideStore (recommended): add the source with the button above, then install Merge Defense. Updates then appear in the app.
  2. Sideloadly: download the IPA above and install it from your computer. For updates, download the new IPA and install it again.
  3. Apps installed with a free Apple ID expire after 7 days and must be refreshed (AltStore and SideStore can do this automatically).
Android: install and update
  1. Download the APK above and open it.
  2. If asked, allow installing from this source ("unknown sources") for your browser or file manager.
  3. To update, download the newest APK and install it over the old one. Your data is kept.

The game shows an in-game hint when a newer version is available.
